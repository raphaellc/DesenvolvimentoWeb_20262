A propriedade CSS position

A propriedade position define como um elemento é posicionado na página. Seus principais valores são: static, relative, fixed, absolute e sticky. Veja abaixo um exemplo de cada um.

1. static (valor padrão)

Todo elemento nasce com position: static. Ele segue o fluxo normal da página e as propriedades top, right, bottom e left não têm nenhum efeito sobre ele.

static

2. relative

O elemento continua ocupando seu espaço original no fluxo da página, mas pode ser deslocado visualmente a partir dessa posição usando top, right, bottom ou left. Note que o espaço que ele ocupava antes continua reservado.

relative
(top:20px; left:40px)

3. absolute

O elemento é retirado do fluxo normal da página (não reserva mais espaço) e é posicionado em relação ao ancestral mais próximo que tenha position diferente de static. Aqui ele está posicionado em relação à caixa tracejada, que é relative.

absolute
(top:15px; right:15px)

4. sticky

É um híbrido entre relative e fixed: o elemento se comporta como relative até que a rolagem atinja o limite definido (top: 0, neste caso) — a partir daí ele "gruda" no topo do contêiner com rolagem. Role a caixa abaixo para ver o efeito.

5. fixed

O elemento também é retirado do fluxo normal, mas fica fixo em relação à janela do navegador (viewport), não se movendo nem quando a página inteira é rolada. Um exemplo clássico é um botão flutuante. Role toda a página para ver a caixa vermelha no canto inferior direito permanecer sempre visível.
